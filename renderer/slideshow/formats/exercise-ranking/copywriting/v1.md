# exercise-ranking Copywriting v1

## Scope

This version governs English copy for `slideshow/exercise-ranking`. The format helps a lifter compare or prioritize a bounded set of exercises for one named decision. It owns the language roles, ordering logic, density, and progression—not exercise truth, scoring evidence, product claims, project geometry, or imagery policy.

The designated source post is execution evidence for a cover followed by individually ranked exercise cards with short rationales. Its exact exercise set, scores, wording, personal physique claim, and product insert are not reusable evidence.

This namespace is not on the production allowlist. It may not generate a new publication-ready content record unless the user later adds it to `context/production-formats.json`.

## Decision and evidence gate

Before drafting, define one comparison question and one decision-relevant criterion that accepted expertise can support. Examples of criterion classes include equipment fit, setup practicality, stability demand, or another bounded tradeoff; the format itself establishes none of them.

- Do not rank exercises by vague overall quality, muscle growth, safety, or necessity.
- Do not convert personal preference into a universal score.
- If numeric scores are used, define the scale and anchors before applying them consistently. Prefer ordinal placement or bounded categories when evidence does not justify numerical precision.
- Preserve relevant setup, population, technique, injury, and goal limitations.
- Use fewer items rather than padding the ranking with weak comparisons.

## Sequence

Use one cover followed by four to seven item slides. Every slide must deliver decision value; omit a separate recap unless the conclusion adds a distinction not already visible.

1. **Cover:** name the bounded exercise set and the exact comparison criterion.
2. **Item slides:** show one exercise or setup per slide, its position or bounded grade, and one concise rationale tied to the criterion.
3. **Resolution:** the final ranked item may deliver the strongest recommendation only when the same evidence standard supports it; ranking order alone is not proof.

The source's personal starting-physique slide is not a reusable proof device. Use personal context only when LIFT CODE owns genuine first-party evidence and the context materially explains the criterion. The source's app screen is not part of the reusable grammar and must be omitted during the current no-product prelaunch phase.

## Item-slide language roles

Each item slide uses no more than three primary roles:

1. **Position or grade:** compact, consistent across the sequence.
2. **Precise exercise name:** include setup qualifiers that change the movement.
3. **One bounded rationale:** explain the decision-relevant tradeoff in one or two short sentences.

Do not add a second coaching paragraph, unsupported mechanism, transformation promise, or universal programming rule. A concise caveat may replace the rationale when the limitation is the decision value.

## Hook, voice, and rhythm

- Lead with a concrete comparison the viewer can understand before inspecting the image.
- Use direct, familiar U.S. gym language without imitating the source's expressions.
- Keep the tone experienced but non-authoritarian: confident enough to compare, explicit about scope.
- Avoid rage-bait rankings whose only mechanism is a provocative score.
- Vary sentence rhythm across slides while keeping label grammar stable.
- Let the ordering create progression; do not add filler transitions.

## Title and caption

Provide a separate concise post title. The caption states the criterion, one important limitation, and any context that cannot fit naturally on the slides. During prelaunch, use no audience-facing CTA and make no app claim.

## Adaptation reasoning

The reference earns attention through an immediate body-region promise, candid first-person exercise imagery, sequential rankings, and short opinionated rationales. LIFT CODE retains the low interpretation cost and progressive comparison while replacing unsupported absolute judgments with an explicit criterion, bounded evidence, precise exercise identity, and honest limitations.
